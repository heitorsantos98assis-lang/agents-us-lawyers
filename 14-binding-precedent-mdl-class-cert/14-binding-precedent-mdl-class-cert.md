### 2. MDL workflow

```
WHEN TO PURSUE MDL TRANSFER
- 5+ parallel federal cases with common factual issues
- Defendant (or plaintiffs) want centralized discovery
- Class action not certifiable but mass tort

MOTION TO JPML (Form Section)
- Specify cases proposed for transfer
- Identify transferee district + judge preference
- Common factual issues + benefits of consolidation
- Hearing typically held quarterly (March, May, July, October, December)

POST-TRANSFER
- Initial CMO sets PSC selection process
- Common-benefit fund (typical 7-10% of recoveries)
- Bellwether selection (representative cases)
- Discovery coordination
- Daubert + dispositive motions
- Mediation typical post-bellwether
```

### 3. Class certification workflow

```
PRE-CERT
- Define class precisely (Rule 23 ascertainability — circuit split)
- Identify class representative + adequacy
- Plan discovery (Rule 23(c)(1)(A) — "at an early practicable time")
- Set briefing schedule per scheduling order

CERT MOTION (Plaintiff)
- 23(a) numerosity: census / lawful identification of class size
- 23(a) commonality: identify common questions whose resolution will produce
  common answers (Dukes)
- 23(a) typicality: representative claim arising from same event/conduct/practice
- 23(a) adequacy: no conflicts; experienced class counsel
- 23(b)(3): predominance — common issues predominate over individual; show
  damages model under Comcast; address materiality if securities (Halliburton II)
- 23(b)(3): superiority — class > individual actions
- Address Article III standing post-TransUnion — every class member must be injured

CERT OPPOSITION (Defendant)
- Attack each 23(a) element with factual record
- Attack predominance — show individualized issues (causation, reliance, damages)
- Attack damages model — Comcast challenge
- Standing — TransUnion attack on uninjured class members
- Manageability + superiority — choice-of-law issues for multi-state class

POST-DENIAL / POST-GRANT
- Rule 23(f) interlocutory appeal — 14 days from order (no extension)
- Discretionary acceptance by court of appeals
- Settlement class certification — separate analysis (Amchem; Ortiz)
```

### 4. En banc / circuit-split strategy

```
WHEN TO PURSUE EN BANC
- Intra-circuit conflict (panel decision contradicts prior panel)
- Issue of exceptional importance
- Maintain uniformity with sister circuits

FRAP 35 PETITION REQUIREMENTS
- File within 14 days of panel judgment
- 3,900 word limit (15 pages)
- Specify (a) panel decision conflicts with prior decision; (b) exceptional
  importance
- Pre-en banc settlement negotiation often productive

CERT TO RESOLVE CIRCUIT SPLIT
- File petition within 90 days of court of appeals judgment (S. Ct. R. 13)
- 9,000 word limit
- Highlight (a) circuit split; (b) issue of national importance; (c) deepening
  conflict warrants resolution
- Acceptance rate ~1% — focus on objectively strong cases
```

### 7. Anti-patterns

- Pursuing class cert without ascertainability analysis — circuit split applies (3d Cir. requires; 7th/8th/9th rejected).
- Filing Rule 23(f) petition after 14 days — jurisdictional.
- Treating settlement class as same standard as litigation class — *Amchem*/*Ortiz* require trial-class analysis.
- Bringing offensive non-mutual issue preclusion without *Parklane* factors briefed.
- Conflating Article III standing with class membership — every damages class member must independently have standing post-*TransUnion*.
- Confusing pre-cert factual findings with merits — *Eisen v. Carlisle & Jacquelin*, 417 U.S. 156 (1974) is largely displaced by *Comcast*/*Dukes*; courts now consider merits insofar as relevant to Rule 23.
- Joining unrelated MDL cases — JPML rejects if not common-fact.
- Filing en banc petition on a circuit-split argument — en banc is for intra-circuit, not inter-circuit; cert petition is for inter-circuit splits.

### 8. Edge cases

- **Voluntary dismissal post-cert denial:** *Microsoft v. Baker*, 582 U.S. 23 (2017) — no appealable final judgment.
- **Mass action vs. class action:** 28 U.S.C. § 1332(d)(11) — 100+ plaintiffs proposed for joint trial.
- **Settlement class with no contested cert:** rigorous Rule 23 review still required.
- **Coupon settlements:** CAFA § 1712 — attorney fees tied to redemption rate.
- **Cy pres distribution:** *Frank v. Gaos*, 586 U.S. 485 (2019) — cy pres-only settlements scrutinized; standing question reserved.
- **Notice and opt-out:** Rule 23(c)(2)(B) — "best notice practicable"; *Eisen v. Carlisle & Jacquelin* notice requirement.
- **State-court class actions:** local-controversy exception under CAFA § 1332(d)(4); home-state exception.
- **Securities class actions:** PSLRA lead-plaintiff procedures (15 U.S.C. § 78u-4); fraud-on-the-market presumption (*Basic Inc. v. Levinson*).
- **Antitrust class actions:** *Comcast* damages-model rigor.
